# BrainBoom X2 - Jungle adventure

Seven physical pages: Home, Create, Creature, Play, Speak, Grow, and Player Profile. The visual theme follows the selected leafy jungle-frame direction with a CSS-drawn canopy/vine treatment around a bright, readable content area. The reference image's watermark is not used.

Play has Grammar Garden, Sentence Studio, and the final Story Chapter. Each lesson leads to a checkpoint; players need at least 80% to unlock the next stage. Progress and player name save in the browser. A character-guide placeholder sits beside each learning activity. Player Profile includes progress and a saved collection of created creature icons.

The Part 2 card system, creature profile and PNG + JSON save, original art assets, schema, and Vercel API are retained.

## Deploy
1. Extract this ZIP.
2. Copy the contents of BrainBoom-X2-Part2 into the root of the same GitHub repository. Keep all seven HTML pages and supporting files together.
3. Commit and push. Vercel will redeploy the updated static site.
4. Keep STABILITY_API_KEY configured in Vercel. The existing backend URL is still in script.js.

Use the website root for Home. Each menu link opens its own HTML page.
